4. Langkah SPSS yang dipakai

  1. Masukkan data uji coba 20 responden ke Data Editor SPSS.
  2. Klik Analyze → Scale → Reliability Analysis.
  3. Masukkan semua skor butir ke kotak Items, pilih Model: Split-half.
  4. Di Statistics, centang Descriptives for Item, Scale, Scale if item deleted, dan Inter-Item Correlations.
  5. Klik Continue, lalu OK.
